Private editorial notes stay outside the markers.

Writing and deploying are different jobs. A preview lets me check the words before
changing the website.

## Three deliberate steps

1. Write the draft in Markdown.
2. Inspect the rendered page.
3. Write the reviewed version and verify its bytes.

| Step | Changes the post? |
| --- | --- |
| Preview | No |
| Write | Yes, locally |
| Verify | No |

```bash
printf 'Write first. Publish deliberately.\n'
```
